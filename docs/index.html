Sticky Notes

轻量级 Windows 桌面便签
无边框透明窗口，每个便签独立管理

Tauri 2 React 19 ~10MB MIT
下载安装包 查看源码

核心功能

📝

多便签管理

每个便签独立窗口，自由创建、复制、删除

🎨

12 种颜色

右键菜单选色，透明度 20%–100% 可调

📌

置顶 & 锁定

便签置顶显示，锁定防误编辑

📎

窗口吸附

便签自动吸附屏幕边缘和其他便签

✅

待办复选框

Ctrl+1 插入，完成时放烟花

⌨️

全快捷键

新建、复制、重命名、置顶、字号、透明度…

🔄

折叠/展开

折叠为仅标题栏，节省屏幕空间

📤

导出便签

复制式/剪切式导出到剪贴板

技术栈

前端 React 19 + Vite + CSS Modules
后端 Rust + Tauri 2.x + rusqlite
存储 SQLite 本地存储
体积 ~10MB 安装包，低内存占用
